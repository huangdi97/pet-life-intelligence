## v0.1 必须能演示的 7 条端到端路径

### E2E-01 创建宠物 → Today → Timeline
- 创建 Pet
- 切换多宠
- Quick Log 一条喂食事件
- Today 可见
- Timeline 可见
- provenance 可查

### E2E-02 家庭协作
- Owner 邀请家庭成员
- 分配角色
- 创建 Task
- 第二成员完成
- 显示 completed_by
- 审计可见

### E2E-03 重复执行冲突
- 同一任务被多人尝试重复完成
- 系统给出明确冲突提示
- 不静默覆盖
- 保留审计

### E2E-04 临时照护交接
- 创建 Care Handoff
- 生成 Care Card
- 临时角色只能读取授权字段
- 到期自动失效

### E2E-05 健康事件
- “发现异常”
- 动态追问
- 上传证据
- AI/规则提取“可观察事实”
- 红旗规则
- Monitor / Vet Soon / Urgent / Emergency
- 生成 Vet Brief

### E2E-06 用药与 Outcome
- 建立用药计划
- 给药记录
- 遗漏提醒
- 健康事件后续
- Outcome：恢复 / 未改善 / 复发 / 转诊

### E2E-07 行为记录
- 创建 BehaviorEvent
- 记录前因/行为/后果/上下文
- 绑定媒体
- 出现在 Timeline
- 不把行为观察自动升级成疾病诊断
