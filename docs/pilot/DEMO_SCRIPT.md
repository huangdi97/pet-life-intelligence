# DEMO_SCRIPT — 5–8 分钟产品演示脚本

目标听众：宠物医院 / 宠物店 / 训练师 / 宠主。演示使用**完全虚构**的 demo 宠物，不涉及真实用户数据。

## 准备

- 浏览器打开 Web（或演示手机浏览器 PWA）。
- 登录 demo 账号（dev/staging 环境：`owner@pli.demo`）。
- 或现场注册一个真实账号（pilot 需邀请码）。

## 1. 宠物身份（30s）

- 演示宠物：豆包（Corgi，2 岁，已绝育）。
- 展示宠物档案：名字/种类/出生/体重/家庭。

## 2. Today 今日总览（30s）

- 首页「今天怎么样？」：今日事件计数 + 待办任务。
- 顶部宠物切换（多宠家庭）。

## 3. Quick Log 快速记录（30s）

- 点「喂食 / 饮水 / 排泄 / 散步」→ 即时入 Timeline，带来源与记录人。

## 4. 家庭照护（45s）

- 展示照护授权列表与到期时间。
- 展示 Care Card 生成与分享链接（匿名可读，到期失效）。

## 5. 行为 ABC（45s）

- 用 ABC 结构记录一条行为（前因→行为→后果），强调不做主观定性。

## 6. 健康事件闭环（90s）

- 「发现异常」：主诉"呕吐两次，精神略差"。
- 系统追问 → AI 整理观察（标 AI_DERIVED）。
- 独立规则引擎红旗 → 分级（如 VET_SOON）。
- 生成 Vet Brief → 展示可分享链接（给兽医）。

## 7. 用药与结局（45s）

- 用药计划 → 给药记录（重复给药被拦截）。
- 记录 Outcome → Timeline 可见。

## 8. 搜索 / 助手（60s）

- 问："最近 30 天体重有什么变化？"
- 展示回答引用真实事件、时间、来源；事实与推断分离。

## 9. 收尾（30s）

- 强调：AI 不诊断；红旗由独立规则引擎；数据可导出/删除；所有访问留审计。

## 话术要点

- "这不是一个聊天机器人，是一个事件化的宠物生命档案。"
- "任何一条记录都回到同一个 Pet ID 与 Timeline，多端一致。"
- "医疗安全不依赖 AI 在线；规则引擎独立运行。"

## 演示失败预案

| 问题 | 处理 |
|---|---|
| 网络断 | 展示 PWA 离线壳 + 重试 |
| AI 未配置 | 说明 fallback 到确定性引擎，核心功能不受影响 |
| 演示库数据被改 | 使用新注册账号演示（真实流程更可信） |
