# INTERVIEW_GUIDES — Stage G 访谈体系

> Agent 不假装访谈、不伪造访谈结果。Agent 负责：设计访谈、整理用户提供的真实访谈结果、归纳证据。
> 每次访谈记录来源（谁/机构/日期/时长）；无访谈即 `NOT_YET_OBSERVED`。
> 访谈记录默认匿名化，先征得同意再引用；机构名/宠物身份/医疗详情未经许可不公开。

## 0. 通用规则

- 问真实过去行为，不问抽象愿望（「上一次…你当时做了什么？」优于「你想不想要…？」）。
- 不引导、不推销；多听少说。
- 每场 ≤ 30 分钟；结束时复述要点确认。

## 1. Owner Interview（宠主）

- 平时怎么记录宠物？（本子/手机相册/聊天/什么都不记？）
- 上一次健康问题（或异常）是怎么发现的、怎么处理的？
- 家里多人养宠时怎么沟通？有没有重复喂食/漏喂/重复用药发生过？
- 什么最容易忘？
- 什么时候会打开 PLI？什么情况下不会打开？
- 今天打开 app 第一眼想看什么？
- 时间线对你来说是真有用的历史，还是只是「功能很完整」？
- 上一次用 Quick Log 记了什么？为什么那次愿意记、其他时候不记？

## 2. Vet Interview（兽医）

- 诊前最缺哪些信息？
- 宠主最常描述不清什么？（时间线/剂量/既往史/行为变化？）
- Vet Brief 里哪些内容有价值？哪些是噪声？
- 有没有误导性内容？有没有重要信息缺失？
- 这份 brief 是否省了时间？下次来诊前还想不想要？（1–5 + 自由文本）
- Outcome 回流（治疗后主人回填结果）现实吗？你愿意点一下吗？

## 3. Trainer Interview（训练师）

- 主人回家后执行训练计划最大的困难是什么？
- 哪种连续记录对你最有价值？
- 哪些行为描述最常失真？（主人描述 vs 实际情况）
- 你会不会真的去看 Timeline？多久看一次？
- ABC 记录对主人来说是不是太难？

## 4. PLI Companion — Product Discovery（不做产品，只收集证据）

核心问题：
1. 主人离家后会不会主动想查看宠物？一天几次？
2. 现在用什么设备？（摄像头/喂食器/饮水机/猫砂盆/项圈/秤…品牌、频率）
3. 只是想看，还是想互动？（说话/投喂/玩具）
4. 宠物有没有回应？主人担不担心打扰宠物/喂过量/隐私？
5. 上次在外面想看宠物是什么时候？当时做了什么？看完后做了什么？

记录字段：
monitoring_frequency / remote_voice_usage / remote_treat_usage / remote_toy_usage /
device_owned / pet_response / privacy_concern / welfare_concern / willingness_to_use

成功信号（真实证据足够才进入设计，阈值按样本校准）：
- ≥30% active owners 已主动用摄像头观察宠物；或大量用户反复出现「离家想看/想陪宠物」的真实行为。

Welfare Risk 记录：频繁打扰、远程投喂过量、摄像头隐私、多人控制冲突、远程玩具安全、宠物逃避/应激。
（未来 Interaction Welfare Guard，Stage G 不实现。）

## 5. 价格访谈（Commercial Discovery）

- 现在为类似问题花多少钱？（记录工具/摄像头/喂食器/咨询服务实际支出）
- 替代方式是什么？（不做 PLI 时你怎么做）
- 谁应该付钱？（宠主/机构/医院？）
- 什么价值值得付钱？（说一个具体场景）
- 不解决这个问题的成本是什么？（忘喂药住院？错过症状？）
- 机构：愿意试点吗？愿意为哪些功能付费？预算区间？

## 6. 证据归档

每次访谈结果进：`reports/pilot/COMPANION_DISCOVERY.md`、`COMMERCIAL_DISCOVERY.md`、
`UX_FRICTION_LOG.md`、`FEATURE_REQUEST_BACKLOG.md`（按证据归属），并在当周 WEEK 报告汇总。
