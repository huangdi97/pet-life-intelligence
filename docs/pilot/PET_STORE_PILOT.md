# PET_STORE_PILOT — 宠物店试点

## 定位

- 帮助门店建立**会员宠物长期档案**：体重、营养、基础健康观察、照护记录。
- 强化"宠物终身会员"关系，而非一次性买卖。

## 试点价值

1. **宠物长期档案**：每次到店的体重/营养/健康观察连续记录。
2. **Care 协作**：店员的照护记录与主人/家庭共享。
3. **体重与营养**：体重记录（不可静默覆盖）+ 营养记录。
4. **会员关系**：里程碑（生日/纪念日）、回忆、成长记录。

## 试点流程

```
宠物建档（到店/线上）→ 店员绑定角色 → 日常记录体重/健康观察
→ 主人授权店员查看营养与照护记录 → 长期随访
```

## 边界

- 不替代兽医；发现红旗引导就医（规则引擎提示 VET_SOON/URGENT）。
- 商品推荐：只在"照护"场景展示，医疗页面不推商品。

## 试点角色

- 店员（Caregiver）：记录体重/健康观察/照护。
- 店长：查看门店会员宠物档案汇总。

## 成功指标

- 建档宠物数、月度记录数（Events/Pet/Day）。
- 到店复购与档案连续记录的关联。
