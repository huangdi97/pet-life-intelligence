# VET_PILOT — 医院/兽医试点

## 定位

- PLI 提供**院前资料整理 + 就诊摘要 + 授权时间线 + 结局回写**。
- **不替代 HIS，不替代诊断**。兽医始终是诊断与治疗方案的决定者。

## 试点价值

1. **院前资料**：主人已把主诉、出现时间、历史记录、用药、媒体证据整理进 Vet Brief。
2. **Vet Brief**：一份能给兽医直接看的结构化摘要（信息整理，非诊断）。
3. **授权 Timeline**：主人通过分享 token 授权兽医查看相关时间线。
4. **结局回写**：兽医可写 Outcome / 诊疗结果（受控授权），回到 Timeline。
5. **长期档案**：历次健康事件的连续记录，便于慢病随访。

## 试点流程

```
主人发现异常 → 记录 → 红旗/分级 → Vet Brief → 分享链接给兽医
兽医打开摘要 → 查看授权时间线/证据 → 诊疗 → 回写 Outcome → 主人看到恢复建议
```

## 边界（必须明确）

- PLI 不做在线诊断、不开处方、不替代医院系统。
- AI 输出带 disclaimer；紧急程度以独立规则引擎与兽医判断为准。
- 访问全部留审计；主人可随时撤回授权。

## 试点角色

- 主治兽医：查看 Vet Brief、授权证据、回写 Outcome。
- 前台/助理：整理病历导入（来源分级）。
- 主人：记录、分享、授权。

## 成功指标（试点）

- Vet Brief 生成 → 兽医打开率。
- 从分享到回写 Outcome 的闭环时长。
- 主人复查（再次就诊）时的档案连续性。
