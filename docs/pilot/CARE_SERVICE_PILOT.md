# CARE_SERVICE_PILOT — 寄养/服务商试点

## 定位

- 让寄养/上门服务商通过 **Care Card + Handoff + 用药 + 每日更新** 提供可追溯的照护。

## 试点价值

1. **Care Card**：一份交接卡（紧急联系、饮食、用药、特殊注意、禁忌）。
2. **Handoff 交接**：开始/结束时间 + Caretaker + 自动撤权。
3. **用药**：按主人计划给药并记录（重复给药被拦截，不自动改剂量）。
4. **每日更新**：每天的生活/排泄/饮食/精神状态记录，主人可见。
5. **结局**：照护结束后的总结与 Outcome。

## 试点流程

```
主人创建交接（授权服务商+时间窗）→ 自动生成 Care Card
服务商按卡照护 → 每日记录 → 结束 → 权限自动收回
```

## 边界

- 服务商只有时间窗内的有限授权；结束即失效。
- 医疗决策仍归兽医；红旗触发会提示就医。
- 媒体证据可上传（照片/视频），但访问受控。

## 试点角色

- 寄养/上门服务商（Caregiver）：Care Card、用药记录、每日更新。
- 主人：发起交接、查看每日更新、撤销授权。

## 成功指标

- 交接完成率、用药记录完整率、每日更新率、0 越权访问。
