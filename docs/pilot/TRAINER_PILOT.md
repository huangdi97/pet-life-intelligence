# TRAINER_PILOT — 训练师试点

## 定位

- 让训练师用**ABC + 训练计划 + Session + 进展 + Outcome** 结构化协作，
  替代"微信发视频+口头描述"的散乱方式。

## 试点价值

1. **行为 ABC**：前因→行为→后果 + 环境/人物/动物，不写"就是攻击型"这类标签。
2. **训练计划**：目标 → 拆解 → Session（提示/奖励/时长）。
3. **进展追踪**：每次 session 的进度与 Outcome。
4. **行为干预计划**（受控）：在主人授权下记录干预与效果。
5. **安全过滤**：建议只输出正向强化；惩罚/暴力方法被过滤并记录理由。

## 试点流程

```
主人记录行为 ABC → 训练师评估 → 制定目标计划 → 分次 Session
→ 记录进展/Outcome → 主人持续记录 → 复盘
```

## 边界

- 训练建议不涉及医疗诊断；涉及健康问题时引导就医。
- 不把行为问题写成"疾病"，也不把正常行为写成异常。

## 试点角色

- 训练师：查看授权行为记录、制定计划、记录 Session。
- 主人：持续记录 ABC 与日常。

## 成功指标

- 训练目标完成率、Session 记录数、行为记录连续性。
