## Boundaries

1. **工作区唯一**：项目一切读写/生成/缓存/证据落 `<REPO_ROOT>` 内；不新建 Docker/云 GPU/Notebook/Codespaces/VM/WSL、不 winget/choco/scoop、不 `npm i -g`/`pip install --user`/系统级 Python 安装、不改注册表/永久 PATH/Profile；仅 process-local 环境变量（enter-r2p3d-r1.ps1）。
2. **不下载任何外部模型权重**（用户决策）：缺失权重的 Provider 一律记录 `NOT_AVAILABLE` / `SKIP_BY_POLICY` 并完成接口/fallback/UI/contract 测试，继续其余工作；不得绕道云端。
3. **复用为主**：优先复用本机已有 AVD（`main`）/ SDK / Gradle 缓存 / FFmpeg / Conda/Python；Blender 缺失时先评估现有 runtime 完成 rig/动画/GLB，确为最小必要时才允许 portable Blender 入 `.local\tools\` 并记账；新 AVD / 新 SDK package 仅在书面 `WHY_EXISTING_…` 后最小安装。
4. **许可证纪律**：受限许可证模型（Hunyuan3D 2.1、SPAR3D/SF3D Community License 商业条件、BITE/SMAL/AnimalAvatar、DeepLabCut 研究限制）不得设为默认生产 Provider；也可参考其方法，但生产底座只用商业安全路线。
5. **真实性与诚实性**：截图必须是真实 emulator 捕获；不得伪造 REAL_PET/Identity 验证；不得删测试、弱化断言、添大范围 ignore 让 CI 变绿；未跑项写 `NOT_RUN`。
6. **Git 纪律**：不 force push、不改写历史、不 merge commit；remote main 前进时停下协调；GitHub 仅作为 remote+CI+Release，不在 Web 改代码。
7. **工程规范**：遵循仓库及全局 AGENTS.md（文件 ≤300 行、单一职责、强类型、无 justifiable 逃逸、Twin 数据三层独立版本化等）。
8. **人工闸门**：`HUMAN_VISUAL_ACCEPTANCE` 必须保持 `PENDING`，由用户最终审阅截图后决定；`Identity Validated` / `Product Validated` 不在本轮目标内。
